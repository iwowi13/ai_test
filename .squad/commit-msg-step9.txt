1.9: Auth endpoints (register + login)

POST /auth/register creates a user with bcrypt-hashed password (409 on duplicate
email). POST /auth/login verifies credentials and returns a JWT bearer token
(401 on bad creds). Pydantic schemas live in app/schemas/auth.py; the router is
mounted in main.py. Six new tests cover happy paths and failure modes.

Verify: cd backend && pytest -q  → all green.
